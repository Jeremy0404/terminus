# TypeScript: Hono, SQLite, React (local tool)

## Fits

- One user on one machine (their laptop or WSL), no accounts, data in a single SQLite file under the user's home.
- A cockpit, a helper around other tools, an offline-first personal app.

## Does not fit

- Several users or access from the internet (use `stack-ts-fastify-vue` or `stack-ts-fastify-react`).

## Layout

- `pnpm-workspace.yaml` with `apps/daemon`, `apps/web` and `packages/contracts` (request and response schemas shared by both sides).
- `apps/daemon`: Hono on Node, listening on the loopback interface only; hexagonal layers (`domain` with no framework import, `application` with ports, `adapters` for HTTP, SQLite, the file system); Drizzle schema with migrations generated by `drizzle-kit generate`.
- `apps/web`: React with Vite (`react-ts` template); the dev server proxies `/api` to the daemon.
- Live updates through server-sent events rather than polling.

## Conventions

- The domain layer is pure and unit-tested; adapters get integration tests against a temporary database.
- Data lives under a dot-folder in the user's home, never in the repository.

## Verification

- lint: `pnpm run lint`
- typecheck: `pnpm run typecheck`
- test: `pnpm run test`
- build: `pnpm run build`
