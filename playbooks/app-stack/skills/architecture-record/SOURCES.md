# Sources

- Michael Nygard, "Documenting Architecture Decisions": context, the decision in active voice, and its consequences, so a future reader understands why: https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions
- Claude Code best practices, "Write an effective CLAUDE.md": persistent context should include "architectural decisions specific to your project" and stay short (the approved record joins every run's context): https://code.claude.com/docs/en/best-practices
- Claude Code best practices, "Give Claude a way to verify its work": checks that return pass or fail (the stack's verification commands become the app's deterministic barrier): https://code.claude.com/docs/en/best-practices
