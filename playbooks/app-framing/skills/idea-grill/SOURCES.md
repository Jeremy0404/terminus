# Sources

- Claude Code best practices, "Let Claude interview you": ask about implementation, UI/UX, edge cases, concerns and trade-offs, skip obvious questions and dig into the hard parts, then write a self-contained spec: https://code.claude.com/docs/en/best-practices
- Shape Up, chapter "Write the Pitch": a pitch has a problem, an appetite ("how much time we want to spend and how that constrains the solution"), a solution, rabbit holes and no-gos ("anything specifically excluded from the concept"). The grill collects exactly what the pitch needs: https://basecamp.com/shapeup/1.5-chapter-06
- Anthropic, "Effective context engineering for AI agents": structured notes kept outside the context window (the Decisions section in `idea.md`): https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents
